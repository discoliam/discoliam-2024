<p class="Lead">I'm a freelance WordPress developer based in Bristol, UK. For over a decade I've built fast, accessible, custom WordPress websites for agencies, charities, start-ups and established brands.</p>

WordPress powers a huge chunk of the web, and for good reason. It's flexible, familiar to content teams and has a massive ecosystem behind it. But it's also easy to end up with a slow, bloated site held together by plugins. I build WordPress sites that are lean, easy to edit and built to last.

## What I can help with

### Custom WordPress themes

Bespoke themes built from scratch around your brand and content, not a page builder or a heavily modified off-the-shelf theme. Clean, semantic markup, modern CSS and only the JavaScript you actually need.

### Gutenberg and ACF blocks

I build custom blocks with the WordPress block editor (Gutenberg) and [Advanced Custom Fields](https://www.advancedcustomfields.com/), giving your team a library of on-brand components they can use to build pages without needing a developer, or breaking the design.

### Headless WordPress

Sometimes WordPress works best as a content back end, with the front end built in a framework like [Astro](https://astro.build/). Your editors keep the WordPress admin they know, while visitors get pre-rendered pages served from the edge. This is how I built the [FutureKings](/portfolio/futurekings/) website.

### Performance and accessibility

Already have a WordPress site? I can audit it for performance and accessibility, then fix the issues: cutting down plugins, tidying up the database, optimising images and scripts, and making sure the site works with keyboards and screen readers. When I rebuilt [Sentient Media](/portfolio/sentient-media/)'s site, Lighthouse scores jumped, and both page weight and database size dropped.

### Agency support

I regularly work with design and branding agencies as their WordPress development partner, turning designs into robust, accessible websites. Long-term partners include Oku Studio, Massive Media and Something Familiar.

## How I work

Every project is different, but my WordPress builds usually include:

- A custom theme, built with modern CSS and minimal JavaScript.
- A library of Gutenberg and ACF blocks designed with your content team.
- Accessibility built in from the start, not bolted on at the end.
- Performance budgets, optimised images and careful use of third-party scripts.
- Version-controlled code and a sensible deployment workflow.
- Handover documentation and training, so your team is confident editing the site.

If you're also weighing up other CMSs, I build with [Craft CMS](/services/craft-cms-development/) too, and I'm happy to help you decide which one fits your project best.

Bristol Good Food 2030 is a city-wide framework for making Bristol's food system better for communities, climate and nature. Working with Oku Studio, we built a new website to support that mission, bringing together a large amount of information, resources and ways to get involved.

A big part of the challenge was organising all that content so people could actually use it. We built clean, usable interfaces with WordPress's Gutenberg editor and [ACF](https://www.advancedcustomfields.com/) blocks, giving the team a flexible set of components to present everything from action plans to events and case studies.

Because the project is about the whole city, accessibility was a priority from day one. We aimed for high accessibility standards across the site, with semantic markup, strong colour contrast, clear focus states and careful testing with assistive technology, so the message reaches as many people as possible.
